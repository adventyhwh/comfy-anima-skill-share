# 成人向事件与视觉表达

## 路由

成人向请求先用 `anima-prompt` 确定模板、质量与安全标签、负面词、角色槽和模型参数；本 skill 只补充事件及气氛的判断。公开角色默认用角色名（必要时加作品名）作为身份锚，不因成人向主题而补全人物外观。含 OC 时才读取 `anima-prompt/references/oc.md`，混合画面也只为 OC 使用该分支。

## 从事件核心推导视觉

1. **找核心**：明确事件的心理、身体或关系变化，以及去掉哪一点主题就不成立。道具和服装通常是表达载体。
2. **转成可见信号**：选能直接呈现核心的表情、姿态、双方关系或场景，再选少量道具。例：催眠重在恍惚与意志变化，怀表只是可能的引导物。
3. **选身体语言**：精神抽离可表现松弛与游离；主动转变可表现靠近与迎合；身体定格表现动作中断；关系变化要让人物的位置和接触点可读。
4. **定行为与阶段**：心理或关系主题与具体成人行为是两个维度。让行为服务核心，强度随当前故事阶段变化；无需每张都使用同一种强度或构图。
5. **放进主模板**：核心视觉落在动作、表情和人物关系；环境与道具承托事件；模板 C 的情绪收束或模板 B 的标签分组都依 `anima-prompt` 选择。角色身份槽始终按公开角色/OC 路由填写。

眼神可承担状态变化：`glazed eyes` 表恍惚，`empty eyes` 表意识消失，`heart-shaped pupils` 更偏渴求。词义要与当前阶段一致；必要时用场景、姿态与目光方向共同表达，不让一个标签承担完整剧情。

需要精确选择成人动作、体位、表情或 HCG 效果 tag 时，按需读取 [references/tags.md](references/tags.md)；不把整份词表堆进单张 prompt。

## 套图叙事

- **转折型**：建立常态与动机，经过触发和抵抗，在关键转折后呈现新状态。
- **程度加深型**：同一机制逐渐改变表情、姿态、行为和人与人之间的距离。
- **单事件差分**：固定时地，变化表情、角度或行为。
- **多事件 CG**：不同触发点各有情节作用，场景与状态可随剧情推进。

按题材选择结构，也可组合。画面之间保留足够的状态连续性；余韵页通常让光线和姿态承担收束。

## 主题到视觉锚点

下表是推导参考，不是固定配方。优先依据用户的具体情节判断。

| 主题 | 可用视觉信号 |
|---|---|
| 催眠 | `glazed eyes`、视线固定、引导物；`spiral eyes` 可用于入控瞬间 |
| 女战斗员化 | 战损与服装变化、身份符号 |
| 卖淫或身份坠落 | 场所、服装、表情与生活状态的变化 |
| 苗床化 | 腹部变化与设定中的异质元素 |
| 淫纹 | 明确位置的 `womb tattoo` |
| 邪教 | 祭坛、烛光、仪式构图 |
| 常识改变 | 成人在日常场景中自然接受异常行为的反差 |
| 时间停止 | 悬停物与被截断的动作 |
| 被迫（可叠加） | 抵抗姿态、表情与双方力量关系 |

相邻主题可用意识状态、自我是否在场、身体是否能行动、身份是否改变来区分。视觉信号之间应指向同一个事件核心。

## 气氛选择

每张取少量最能服务事件的信号：眼神与表情、接触点、场景反差、近景质感、POV 或距离感。诱导道具完成叙事作用后可退场；持续性的身份符号只在剧情需要时保留。前段偏氛围与设定时可用模板 C，行为明确且需标签精度时可用模板 B。

## 成人向画师

单图或短篇没有明确风格需求时可不用画师。长篇按 `anima-prompt` 的画师策略确定全本风格，并让不同阶段保持连贯；没有明确对应时，可考虑 `@mika pikazo, @redjuice`，画师串通常控制在两位以内。

| 需求 | 画师 |
|---|---|
| 场景叙事 HCG | `@x1p4early2026` |
| 表情特写、失神 | `@k4nz4r1n` |
| 日常色气、透视 | `@haoni` |

完整的题材画师映射和模型用法以 `anima-prompt` 为准。
