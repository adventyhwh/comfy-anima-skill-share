# 成人向标签速查

仅在需要精确表达成人动作、体位、表情或 HCG 特效时使用。先确定事件核心、参与者和当前帧状态，再从下表取少量能在画面中辨认的 tag。词表不是固定模板；用户的具体意图和模型实际支持的标签优先。

| 画面功能 | 可选 tag |
|---|---|
| 机位与参与者 | `pov`, `pov hands`, `pov chest`, `1boy`, `faceless male`, `silhouette` |
| 体位与动作 | `missionary`, `cowgirl position`, `reverse cowgirl position`, `doggystyle`, `spoon position`, `paizuri`, `fellatio`, `groping`, `skirt lift` |
| 身体反应与触感 | `trembling`, `arching back`, `skindentation`, `sweat`, `shiny skin` |
| 羞耻或抵抗 | `teary eyes`, `biting lip`, `heavy blush`, `furrowed brows` |
| 沉醉或恍惚 | `half-closed eyes`, `glazed eyes`, `heart-shaped pupils`, `drooling` |
| 强烈表情 | `ahegao`, `rolling eyes`, `tongue out` |
| HCG 画面效果 | `afterimage`, `motion blur`, `motion lines`, `impact lines`, `onomatopoeia`, `sound effects` |

在模板 B 中分别放参与者、动作、表情及效果，再用一句简短自然语言解释标签难以表达的接触点。POV 或 faceless 构图要说明谁在画面里、哪些部位可见，避免把执行动作的人物留成无归属的身体部分。同一部位的表情或动作保持物理上兼容；跨图表情按故事阶段选择，不把高潮符号当作持续身份特征。
