# 风格参考：平面设计单帧（杂志封面／专辑封面／版式作品）

**激活词**：平面设计感 / 杂志封面 / 版式 / 专辑封面 / 设计作品感。

**定位**：第一眼精致、醒目、足够“唬人”的现代平面设计作品。默认横图，不取复古风格；不追求叙事感或一眼读懂。以下只定风格方向，具体形式随主题生长，prompt 由主流程承接。

## 方向倾向

**字体编排与平面色块是主要设计语言**

typography、色块与图形直接参与构图，和人物、图像共同建立版面的重心、分区与节奏。文字可有可无，组合方式自由，但全幅应有鲜明的平面设计感，不能只靠漂亮插画加装饰或电影光影成立。

**有限调色板与疏密对比**

优先有限调色板，主色、辅色与强调色有明确分工。撞色、多色均可，避免过多独立色相争抢注意力。留白与密集区域互相衬托，复杂而有层次，不堆砌元素。

**人物美型，与另一元素共同成为看点**

人物优先中景，脸清晰、五官精致、姿态有吸引力，不能缩成点缀。与场景、物件或图形融合交互，通过叠压、尺度和前后关系形成层次；具体取景与配合方式不固定。

**媒介质感按需使用**

印刷、纸面或数字媒介质感可以丰富画面，服务于整体的现代审美；不必依赖某种实体物件或概念机关来证明设计感。

参考图用于校准设计感、层次与美型水准，不作为物件、配色或版式菜单；具体构思从当次主题与人物重新推导。
