# 风格参考：抽象与印象绘画单帧

**激活词**：抽象绘画 / 抽象派 / 印象派 / 印象式绘画 / 绘画性抽象。

**定位**：用印象与抽象的绘画方式画出的二次元单帧。二次元的角色与审美是底色，不取写实人物或真实系题材。画法作用在形体本身：角色被笔触、色面、墨或剪纸重新构造，场景退成一片底子——不是给一张普通插画换载体或材质。以下公理描述这类画的感染力如何成立；选题与具体 prompt 由主流程承接。

## 三公理

**公理一 · 一个动作引出一场转化**

画面的神来自一次看得见的转化：甩出的丝带卷成满幅笔圈，跳水的人被拉成一道斜砍的颜料，头化作香炉里升起的烟。转化由角色的动作或处境引出，动作给出原因，转化给出意味；只有"变成了什么"而没有来由的画，容易意义不明。

**公理二 · 夸张的笔触强调事物本来的属性**

动作的方向、布的飘扬、烟的盘旋、墨的渗流、纸的刀口，笔触把这些原本就有的属性放大到超出写实，转化由此成立。画法从形体与动作自身长出来，而不是覆在插图表面；逆光、景深、光斑这类镜头效果替代不了笔触。

**公理三 · 姿态为主，转化为次**

观看先认出角色的姿态或动作，再看到转化。转化从身体的某一部分长出、顺着动作的方向走，大到吞没姿态时画面只剩一团笔触；纸张、色块等媒介自身抢成主体时，角色又会退为角落里的点缀。场景只留底色与少量呼应物，不分走注意。

## 推导

从题目中找出最想留下的感受，落成角色的一个动作或处境，再推这个动作会引出怎样的转化，看其中事物本来有什么属性，选最能把它夸张出来的画法。prompt 写画面本身，保持简短：人物身份按 anima-prompt 的公开角色/OC 路由填写，本文件只补动作与画法；转化直接写成形体或笔触变成了什么；媒介给一段完整描述，写足这种画法自身的痕迹；结尾用一句短语点出转化。清晰与消融交给画法本身，不在 prompt 里分配哪里清楚、哪里溶掉。
