# 定位与调用

本 skill 回答「这一帧凭什么被记住」。在已有故事或画面意图之上，先确认观众预期，再选一个能放大核心的得体变化。只在用户明确点名 `anima-change`、`MUTATE`、画面突变、记忆点、眼前一亮等诉求，或对比方案明确把它列为变体时使用。长篇分镜中只作用于指定页。

它提出画面决策，不重写剧情，也不负责 `anima-prompt` 的 A/B/C 模板、画师选择、负面提示词或模型参数。角色来源不改变本方法；这里无需 OC 专用分支。

# 推导四步

1. **核心**：这一帧最值得保留的是哪个动作、关系或视觉信息？用一句具体的话写出，避免只写题材词。
2. **预期**：读者通常会怎样看见这个场面？确定可辨认的基线，保留让题材成立的部分。
3. **一次变化**：从视角、构图、色调、人物在场方式或关键瞬间中，选一个能放大核心的变化。变化来自本帧的需要，不从形式列表拼装。
4. **视觉载体**：把变化落在明确可画的形状、空间关系、光色或动作状态上。一个主载体通常足够；辅助元素只用于说明它。

用一句话记录结果：`核心 → 预期 → 一次变化 → 视觉载体`。再用三个判断检查它：观众在一眼内能认出原本的题材和人物吗？变化离开解释文字后仍能从画面看出吗？它是否放大这帧的事件，而不只是给画面加装饰？若变化削弱了单帧事件的可读性，回到基线或换一种载体。

把视觉变化优先放在**画面中占有足够面积且关系清楚的载体**上：大块明暗、色面、人物与场景的距离、前景遮挡、动作方向或已建立物件的状态。微小表情、细物件和一句抽象气氛也可以辅助，但如果整张图的变化只靠它们才能被读出，先考虑放大为姿态或空间关系。不要把“强光、倾斜镜头、动态姿势”当成可叠加的效果菜单；每项形式应由本帧的核心与观众预期推得。

# 可用的呈现方向

下表用于把想法转成可见画面，并非固定配方。

| 方向 | 可以如何呈现 |
|---|---|
| 色调 | 保留一处关键色，或让色温随情绪转换 |
| 取景 | 通过门框、窗、帘或前景物限定观看范围 |
| 视角 | 改变高低关系，突出人物之间的权力或距离 |
| 在场性 | 用遗留物与空间状态提示一个人的离开 |
| 瞬间 | 选择选择刚作出、接触刚发生或动作即将完成的一刻 |
| 环境 | 让已建立的场景标志物改变状态，回应故事变化 |

形式要服务叙事焦点。视觉变化尽量在单帧内读得出，也要与分镜里已经确定的人数、接触点和 POV 归属相容。不同页可使用不同方法，未找到合适变化的页保持原有设计。

# 分镜接口

在 `anima-doujin-plan` 的分镜表中，标题列可加 `◆`，承接列写 `MUTATE: <变化维度>`。这两个记号只是策划标注；转写实际提示词时写可见画面，不写 `MUTATE` 或 `◆`。
