# 对白通用原则

**声音先于说明**：每个角色有自己的句长、用词、停顿与反应习惯。对白最好同时推动关系或情绪；设定信息拆进人物真实会说的话，不让所有人共用一种腔调。

**画面已经说出的事交给画面**：旁白可补时间、地点或画外信息；人物对白保留他对此事的态度、请求或隐瞒。内心独白也应像这个人会想的话。

**节奏符号按语气使用**：省略号表示犹豫或停顿，破折号表示话被打断；感叹号、拖音和爱心符号会改变语气，按人物与场景适量使用。不要靠统一的符号模式代替声线。

落笔后按人物读出声，检查句子是否像口语、说话人与气泡位置是否对应、跨页关系是否连贯。默认写自然中文；用户指定其他语言或文风时按其要求处理。可吸收参考文本的节奏和结构，不照抄具体台词。
