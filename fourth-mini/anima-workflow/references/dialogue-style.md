# 对白写法参考（入口）

对白让人物有声音、态度和关系，不负责复述画面或交代整段设定。写漫画对白、内心独白或单图台词时，按当前页面的语气选用对应篇目。

| 页面语气 | 参考 |
|---|---|
| 日常、热血、悲伤、压抑 | [dialogue-style-safe.md](dialogue-style-safe.md) |
| 暧昧、欲言又止 | [dialogue-style-sensitive.md](dialogue-style-sensitive.md) |
| 成人题材的亲密对白 | [dialogue-style-nsfw.md](dialogue-style-nsfw.md) |

同时读取 [dialogue-style-common.md](dialogue-style-common.md) 的声线与排版原则。长篇可把相近语气的页面放在同一轮写，以保持声线连贯；完成后仍按页码通读对话衔接。
