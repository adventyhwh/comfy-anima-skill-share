# Anima 场景提示词

## 路由

- 环境是主体、人物缺席或只是匿名远景点缀：用本 skill。
- 具名角色是主体：用 `anima-prompt`；环境仍占重要篇幅时，结合本 skill 的空间与光线方法。公开角色以角色名（必要时加作品名）标识；有 OC 时才读取 `anima-prompt/references/oc.md`。
- 场景中的成人情节还需 `anima-nsfw-prompt`。纯场景不加载人物一致性资料。

本 skill 只决定场景特有的提示词结构。质量与安全标签、负面基线和模型参数以 `anima-prompt` 为准；实际生图时使用当前环境可用的生成工作流。

## 从需求确定画面

提取用途、环境主体、情绪、时间与天气、人物是否只是点缀。简短需求可以自行补充有助于表现主题的空间层次和光线；用户已指定的地点、物件与气氛优先。

## 三种结构

### 1. 氛围分层

适合水彩、手绘和叙事场景。按“色板与基调 → 光线 → 建筑/地形/植被主体 → 近中远景细节 → 视角与景深 → 材质 → 情绪收束”组织自然语言；每层承担一个视觉作用，避免把同一形容词反复堆叠。背景人物若存在，只描述其在环境中的活动与尺度。

```text
[质量/安全标签], [风格或画师];
[地点和色板]; [光线如何落在主体上]; [近景、中景、远景的可见元素];
[视角和空间深度]; [材质与天气]; [情绪收束]
```

日常叙事需要抓拍感时，可用 `anonymous figures focused on their own actions, unposed, candid`，不默认让路人看镜头。

### 2. 标签分组

适合元素明确的概念图、游戏背景和地图素材。质量头之后依次写环境主体与独特结构、材质或植被、天气与光线、视角、景深、气氛。

```text
[质量/安全标签], [地点及独特结构], [材质/植被/天气],
[光线], [wide shot / aerial view 等视角], [空间层次], [气氛]
```

### 3. 剖面图

需要同画面展示建筑内外或多层空间时，用 `cutaway, cross-section`，再明确外部轮廓、内部区域与其相对位置、内外光线对比。功能人物可用匿名职业或活动点缀，不为其建立角色身份。

```text
[质量/安全标签], cutaway, cross-section, [建筑外形],
[可见内部楼层/房间及相对位置], [材质], [内外光线对比], concept art
```

结构选择：情绪主导用分层；元素清单明确用标签；内外同时可见用剖面。

## 人物点缀与负面词

纯场景可写 `no central figure`；有人群时用 `anonymous figures`、`distant passersby`、`small figures in the background`。不要为匿名路人加入姓名或完整外观，以免转移画面焦点。

负面词从 `anima-prompt` 的相应模型基线出发，只排除当前画面不想要的内容。雨景、水面和镜面场景不要误压反射；有人群的场景不要误压 `multiple people` 或 `crowd`。水彩氛围图可用简短负面或留空。AES 不使用 `score_*` 标签。

## 场景画师

| 画师 | 风格 | 适用 |
|---|---|---|
| `@sw33t` | 水彩、手绘、氛围强；在目标模型版本上效果未确认时可考虑 `@acky bright` 或水彩风格词 | 雨景、城市、聚会 |
| `@acky bright` | 水彩与线稿、叙事怀旧 | 室内、街机厅、商店 |
| `@shinkai_makoto` | 通透光影 | 天空、云、自然光景、黄昏 |
| `@mucha` | 装饰风与 superflat | 装饰性背景、海报背景 |
| 无画师 | Anima 默认 | 简洁背景、概念图、地图资源 |

场景题材和画师有明确匹配时选择对应画师；不确定时可以不用画师。

## 构图与比例

用 `wide shot`、`aerial view`、`low angle`、`vanishing point` 等确定观察位置；用前景遮挡、引导线、空气透视和光线方向建立深度。情绪由时间、天气、光色与环境材质共同承载。

| 用途 | 建议比例 |
|---|---|
| 场景、风景、桌面壁纸 | 约 16:9 |
| 加载界面、横幅、超宽全景 | 约 21:9 |
| 地图 tile、方形背景 | 1:1 |
| 竖屏场景、手机壁纸 | 约 9:16 |

按实际模型和工作流选择接近目标比例的尺寸。交付提示词时给出正面、必要的负面、画师和建议比例；用户要求实际生图时再提交并核对生成结果。
