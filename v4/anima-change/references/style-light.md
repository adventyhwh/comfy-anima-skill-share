# 风格参考：轻松单帧（喜剧/反转/meme/日常一歪）

**激活词**：轻松向 / 无认知压力 / 快速看懂 / pixiv喜剧。

**定位**：单帧读法层的轻量参考，校准已选题目的画面方向。选题与具体 prompt 写法由主流程承接；以下公理描述本风格的趣味如何成立。

## 三公理

**公理一 · 常态让偏离有意义**

画面的趣味产生于观众熟悉的关系被重新理解：事物的用途、身份或处境与预期形成落差，熟悉的那一面仍使落差可认。轻松来自“原来还可以这样”的迅速领会。共享日常给这次领会提供入口，角色和文化知识让意味继续延伸。

**公理二 · 此刻足以唤起故事**

静帧保存此刻，观众从可见的处境与反应中补出前后，故事在观看中展开。支撑主读法的是眼前关系的自足，来历的留白可以成为趣味的一部分。角色按自身处境行动，其反应与物象共同参与意义的生成。

**公理三 · 轻量来自理解的汇聚**

画面各部分彼此解释时，丰富也可以轻松。主发现把细节组织成一个整体，构图、表情与光色让这个整体更清楚、更有余味。理解被拉向互不相干的故事时，注意力随之分散；主读法的清晰也容得下次要意味。

## 推导

沿用 change 从核心、预期到违反的推导。落到本风格时，从题目中的熟悉关系找到观众的进入点，让当帧的可见关系带来一次重新理解，再围绕这次发现组织画面。形式由关系与表达需要推得，公理用于理解和推导，具体画法随题目生长。
