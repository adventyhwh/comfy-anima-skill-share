# 风格参考：平面设计单帧（杂志封面/专辑封面/版式作品）

**激活词**：平面设计感 / 杂志封面 / 版式 / 专辑封面 / 设计作品感。

**定位**：单帧读法层的轻量方向参考。只描述「设计感从哪来」的倾向，不设硬性禁令——具体画法随题目自由生长，以下条目都是可违反的倾向，不是规则。

## 方向倾向（全部可按题目需要放宽或违反）

**倾向一 · typography 与平面色块是设计感的主要来源**

大字、字阵、栏位、色块边界、框、圆环、点——这些排版语汇在场时，图最容易被认出「平面设计」。人物插画与它们的关系可以很自由：被穿过、被框住、并置、嵌套、或者只是共享一个色调，不拘泥于任何特定咬合方式。

**倾向二 · 限色与留白常出高级感**

单色调、黑白+一个亮色、大面积极简，这些方向实测稳定出片。但不强制——高饱和撞色、多彩拼贴在合适的题目下同样成立。

**倾向三 · 印刷与媒介质感是氛围来源**

网点、套色错位、纸纹、撕边、扫描线、实体印刷物件（书、唱片、磁带、信封、屏幕）——这些质感把画面锚在「设计作品」的语境里。当作氛围香料使用，用量随感觉。

**倾向四 · 人物是美型落点**

人物保持美型与情绪，面部可读。版式与人物的配合方式不设限。

## 实测记录（数据备忘，非禁令）

- 已渲染成功的结构库存（可取用可发展）：巨字标题、网格切割、环形字、撕纸、字叠脸、屏幕内、书脊内嵌、折面分镜、双重曝光、瞳孔倒影、色卡、日历、仪表、碑贴、的手势类小元素等。
- 曾被判「莫名其妙」的批次多为概念机关堆叠（拉链、拼图、火漆、字母雕塑、钥匙孔、制图过程等）——注意这不是说此类永不可用，而是当轮密度过高、且多数缺少 typography 支撑。未来若用，减量、并让排版在场。
- 人物占比曾两次缩水失败（极简圆环 ~20%、电梯按钮 ~8%）——留白骨架注意给人物留足可读尺度。
- 文字可接受乱码级英文（远看即版式）；中文不指望可读。
- 高频元素（条码等）注意降频轮换。

## 探索提醒

每张图至少一个此前没出现过的结构或元素，已验证结构不连续两轮复用；质量与新鲜度分开计分。
