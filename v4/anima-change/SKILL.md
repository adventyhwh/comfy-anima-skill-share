## 定位

**presentation 只回答一个问题：这一帧凭什么被记住。** change 是纯指导：不负责执行（执行细节全在 anima-prompt），不做审查（安全/一致性纪律走主流程），只校准"这一帧的呈现决策"。它不是另一套公式，而是从当次故事现场推导出的、可渲染的破规。

**命题**：让人眼前一亮 = 给足预期 + 一次得体违反。这一句是全部原理。

## 信念（先立后破，防跑偏）

- **原理只有一句，特征都是结果**："强主光/视觉密度点/非常规机位/动态瞬间/环境叙事"是结果不是配方。逐条叠加=贴标签，做出来的是模仿不是作品。
- **预期是被推导的，不是被查表的**：同题材高收藏图的交集=读者期望区；超常作品与同题材的差集=可学的违反点。沉淀的是推导顺序，不是"题材→构图"映射表——查表即模仿。
- **破规必须落在可渲染形状**：抽象的破规（"被操控感"/"匿名张力"）模型渲不出来。违反点必须由完成态动作/空间排列/色调变化承载。
- **回退是合法决策，不是失败**。
- **轻量**：一帧至多一处违反；违反只断视觉不断角色/剧本/安全等级。

## 推导方法（每帧重推，不查表）

顺序固定，四问走完再谈形式：

**① 核心**——去掉什么，这帧就不值得留了？答案是一个载体/关系，不是主题词（主题词是外衣，核心是骨架）。判别式：换掉这个核心，图还能火吗？能=不是真核心，回 ①。核心必须绑题（换场景不成立）。

**② 预期**——读者翻到这页，潜意识要看到什么？推导方式：同题材高收藏的共同点（基于见过的样本，不凭空编）。表达成基线：这帧按惯例会怎么画。判别式：不按这个基线画，读者还认得出这是他的题材吗？认不出=预期没给足，违反要弱化。

**③ 一次得体违反**——预期里哪个维度可以被违反，且恰好放大核心？维度候选来自预期本身（默认视角/默认构图/默认情绪方向/默认叙事/默认留白），不从形式库挑。违反必须：单点、贴核心、可渲染。**分档起手**：弱（惯例内重音）→ 中（惯例颠倒）→ 强（惯例缺席）；直接上强档=猎奇不是惊喜。

**④ 视觉交点**——这个违反用哪些视觉要素显出来？1 主 + 0-2 辅，禁止三要素以上齐上（每个都抢解释权=画面散）。判别式：把其他要素全拿掉，只留这个交点的要素，违反还成立吗？不成立=交点选错，回 ④。

**三问验证**（①-④产出后必跑）：
1. **有强载体吗？** 这个违反点落在模型能稳定渲染的载体上吗？——强载体：强光/光带（唯一亮区、光柱、光束交互）、鲜明色块、大构图（消失点/对角线/前景遮挡景深）、人物与场景的强交互（人立于/驻于视觉锚定点）。**弱载体：手部动作、面部特写（回眸/眼神）、微叙事小物件、均匀细节密度（水面/雪面/灯笼阵列）——这些是模型弱项，押上去钩子落空、反而更普通。** 判别式：这个违反点如果只留一句话写进 prompt，模型画不画得出那个形状？
2. **会牺牲执行层纪律吗？**（正负冲突/排空/预算/角色一致性——执行层归主流程，但违反点不能制造矛盾）
3. **放大这帧的叙事意图吗？** 违反是手段不是目的，为突变而突变=装饰画。

**产出** = 吸引力句一行：`[核心] → [基线预期] → [一次违反] → [视觉交点]`。

**背向陷阱（违反有效性的两个杀手）**：
- **同赛道撞车**：这个违反点在同类热门图里已经出现过？出现=违反失效，只剩"好看"。判别式：图在 timeline 上被划过的瞬间，有没有一个陌生点让它停住？
- **安全到无钩子**：构图/题材太安全=好看但会被划走。没有陌生点，就回 ③ 换维度，不要"保底"地放弃违反。

## 复刻/对标模式（参考图在场时，附属分支）

方向反转：参考图已完成"预期+违反"的设计，任务=**保真提取**，不是重新设计。复刻加违反=改题，不另加。

**提取顺序**（先定看不出的，再定画得出的）：
1. **风格锚最先**：画师 tag 是风格唯一可靠锚点（选与参考图画风匹配的已验证画师，画风差异通过画师切换表达）。画风错=失败一半。`anime coloring` 保留为模型原生基底；介质描述词（油画/水彩/丝绸等）超出模型训练分布，写入=质量崩塌，禁写。
2. **机位是最廉价的保真**：侧视写 from the side，后视写 from behind。机位是"人物关系"的画框，归"画什么"不归"怎么画"。
3. **逐项给具体值**（每项对应原图一个可见维）：
   - 明度：什么档（暗/中/高调）+ 暗部占比 + 光源方向。只写色温词不写明度=回落明亮默认（模型明度先验极强）。方向要绑参照（"唯一亮区是X"/"整体比X暗"），只给档位词方向仍会乱。
   - 主体-相机三件事：裁切线（下缘切到身体哪）+ 占幅比（几成）+ 朝向结构（回眸=背对+头转回+脸可见三件同写）。
   - 多元素画面：主次对比句（主体明显大于X/X大部在画框外）——裸百分比会被强先验元素（鲸鱼/机甲/建筑）吃掉。
   - 材质与身体关系：包裹/披挂/环绕类写"覆盖哪些部位+透过可见什么"，缺关系句=材质被摆到环境里当挂件。
   - 背景：主色调 + 几何元素点名（角落切角/主色块位置/月亮位置颜色）——只写背景词=模型重排几何。
   - 符号：绝对领域（裙摆+裸肤+袜口三段）等轮廓性符号逐件显式写，禁用一个部位词概括整段。
4. **保真自检**：落脚本前对照原图勾一遍（机位/画风/明度/前景动感/符号/信息密度），缺项回炉。回炉结论只沉淀为通用规则——**禁记成"某图案例"（案例标签即打补丁）**。

**复刻的合理目标**：动漫基底平涂，厚涂/柔光/纸纹仅能"弱线稿+柔边+无描边"近似，无法全复刻。复刻保真=保明度+构图+主体关系，不为像素级还原加规则。**氛围/大场景/清晰构图型复刻成功率最高；高姿态动态+厚涂+密集细节最低**——低分型降低保真预期，只保明度+主体关系。

## 形式库（实测可靠的可渲染形状，只做可渲染性校验，不是选组合的菜单）

### ①色调
- 单元素保色（整体去饱和，唯一关键色元素保留）
- 弱暖转冷（同一场景内色调随情绪翻转，光源方向+色温对比写受光元素）

### ②取景
- 视窗窥视（透过门缝/窗框/帘隙看主体，前景遮挡明确）
- 手持对象悬置（角色手持关键道具但不碰颈/不碰脸，道具在画面中悬停）

### ③视角关系
- 高度差+同符号（俯仰角反转，但双方用同一视觉符号呼应，禁同框复制第二枚相同物）

### ④在场性
- 主体缺席·不对称动势（该出现的角色不在，但留有动势痕迹：椅子歪斜/杯子还在冒热气）
- 遗留物须场景既有仪式物（不能凭空造道具）

### ⑤拍法
- 决定性瞬间（caught mid-action：选临界态不选完成态）
- 构图张力：透视挤压/前景巨物/鱼眼/几何骨架/几何切割/嵌套框
- 光影突变（单光源变向/明暗翻转，禁阴阳脸=脸切半明半暗）

### ⑥环境
- 立锚物状态翻转（场景标志物状态变了：开着的门关了/水杯翻了）
- 清场（该有人的场景空了，用遗留物交代去向）

## 禁区（实测失败模式，撞线即弃）

1. POV 置换：突变页改 POV 归属→男手无主/视线混乱
2. 特写手碰颈→读成勒杀；身体细小痕迹特写（咬痕→水泡/红印漂移）
3. 多物象传递特写：一帧传递多个物象→模型脑补错位
4. 易燃比喻词（fire/burn→当真火渲染）与隐喻化突变（改剧本语义≠视觉层）
5. 滤镜媒介词：sepia/grain/letterbox/油画/蚀刻/水彩（风格层不是拍法层）
6. 依赖负面压 face-hidden（突变靠负面词压面部→正面冲突）；阴阳脸（脸切半明半暗→两张脸）
7. 微尺度构图：门缝开度/瞳孔收缩等亚像素级变化→画不出
8. H 动作页构图破坏：接触点密集页禁透视挤压/鱼眼/几何切割（更难的画面还看不清动作，必崩）；H 页突变只走色调/光影
9. 不可渲染载体三类：①过渡态（"正在推门"=两进行中动作同帧冲突）②语义态（"被操控感"）③无主体碎片（悬浮手/雾躯）。突变必须由完成态动作/空间排列承载

## 反模式（防的不是画错，是跑偏）

1. **特征清单当配方**：把"强主光+非常规机位+瞬间感"逐条点上→高完成度的装饰画（有完成度无使命感）。
2. **查表选违反**：看到"框景好"就用框景→违反点从这帧的预期推导，不是从好构图列表选。
3. **违反连发**：一图多违反=又杂又假；这是"惊喜"和"猎奇"的分界线。
4. **配方固化成公式**：把实测成功组合写成"X场景+Y光+Z构图=火"→公式即模仿，与查表同罪。实测知识只以判别式存在（"这个违反点有强载体吗？"），不以公式存在。

## 假设检验纪律（防自我重复）

- 突变维度由"当次故事现场"推导，不从形式库查表组合。
- 连续 3 本不重复同一突变组合；同题材内违反点与最近 3 张/3 本不重复。
- 当读者能预测"你会在这里突变"→回到基线。
- 推导得出"不需要违反"→照走基线。回退不是失败。

## 接口

- 承接列标注 `MUTATE: <突变维度>` + 标题列加 ◆
- **MUTATE 是分镜表标注，落脚本时不得把 "MUTATE" 写进 prompt**（有被模型当画面文字烘焙的风险）
