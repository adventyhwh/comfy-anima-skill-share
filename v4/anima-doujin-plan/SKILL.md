# 定位与前置依赖

**前置依赖：执行本 skill 前必须先加载 anima-prompt**（模板 A/B/C、负面模板、人物一致性、道具/视线/多角色纪律、画师策略、参数都在那里，本文件只引用不重复）。本 skill 管"画什么"（分幕/事件链/波折/镜头/节奏），产出**分镜表**（不是提示词）；落脚本用 anima-prompt 逐页写 prompt。本文件重复出现 anima-prompt 纪律时，以 anima-prompt 为权威。

**核心教训：** 长篇最容易死在"**状态页**"（她站在门口/发呆/看脚）——单帧承载不了时间线性概念。所有页必须是"**事件页**"（脱甲/端托盘被入/看录像里的自己），单帧自解释。

**指导思想：** 目的=产出惊喜，不是流水线。核心=**色气核心分析法**（①找核心→②核心转视觉→③核心性质定姿态→④双轴交织→⑤写进模板，与 anima-nsfw-prompt 同构）与**单元化创新**（核心轴不变，行为轴变奏/混合核心=新 XP）。**条款是参考不是枷锁**——"必须/禁止/强制"级规则只保留技术纪律（参数/负面/模板语法等模型层约束）；"怎么色/什么体位/什么表情/什么结局"全部是推荐级，打破规则带来惊喜但要**有意识**（知道在打破什么、为什么打破）。

# 通用层：分镜理论（SFW 漫画/电影，题材无关）

来源：Oran猪《漫画分镜头》、McCloud《理解漫画》、Eisner《漫画与Sequential Art》、贾内梯《认识电影》、Celtx/Soundstripe 镜头指南等。

## G1. 镜头 → 情绪映射表（选镜头先查这张表）
| 镜头 | 情绪/含义 |
|---|---|
| 低角度 from below | 权力/支配/威胁/英雄 |
| 高角度 from above | 弱小/卑微/无助/被审判 |
| 鸟瞰 bird's eye | 宿命/上帝视角 |
| 平视 from front | 中立/平等/对话 |
| 倾斜 dutch angle | 失衡/疯癫/不安 |
| 特写 close-up | 情绪/亲密/压迫 |
| 近景 | 内心性格 |
| 中景 medium shot | 动作叙事主力 |
| 全景 full body/wide | 环境交代/服装变化/孤独 |
| 远景 | 疏离渺小 |

**组合公式：** 低角+特写=对峙威胁；高角+全景=孤立脆弱；倾斜+特写=心理崩溃。NSFW 特别适用：**垂直机位=权力**——体位/攻受转换页必配角度转换（被支配者俯视，支配者仰视）。

## G2. 页数分配（页码模型：按剧本/分镜判断，参考区间非硬性）
- **页码模型**：短篇 10-15p / 中篇 20-30p / 长篇 50+p——只是参考，不排除 17p 等中间值；实际按剧本体量与分镜密度定
- 三幕比例：幕一约 25% / 幕二 50-60% / 幕三 15-25%
- **20 页标尺（中篇默认参照）**：引发事件 P3-5、中点 P10、最低点 P15、高潮 P16-18、收尾 2 页；平均每 2-3 页一个节拍
- **首尾镜像铁律**：第一页与最后一页之间必须发生"肉眼可见的变化"——首尾两页放一起对比，无变化则故事不存在
- 决定性转折篇幅越短冲击越大（"转"短"承"长）

## G3. 景别节奏（单帧序列的镜头韵律）
- 每页一个视觉焦点（眼睛/透视/高对比处），无焦点重画；相邻页景别差 ≥30%；禁止连续 3 页同景别；同一角度/体位最多连续 3 页，第 3 页必引入变化
- 特写页前后必配全景页（"特写-全景"交替）；每场戏首帧全景定场、末帧特写收情绪；疏密节奏：高潮页用特写/复杂构图，过渡页用简洁全景；景别总趋势 远→近→特写，允许局部回退（正戏中途回中景给喘息）

## G3.5 视觉连贯性（跨页一致性，重要）
**角色锚点：** 每角色定义 3-5 个"不可变特征常量"（发色/发型/瞳色/体态/标志性配件），每页 prompt 必须包含、全本逐字复用（写法见 anima-prompt 人物一致性）。**名字即锚点仅限公开动漫角色（模型记忆）；自创名（OC）对模型无效，禁止只写名字+状态当锚，锚=视觉标签全量**。**环境锚点：** 同一场景段（幕）内固定 1-2 个环境标志物（窗户/床/家具/壁纸），每页至少 1 个在画面中。环境行强制"**地点+2-3 道具+光源+色调**"（写法与视觉签名元素见 anima-prompt 多角色纪律/构图节）。环境随弧线整体迁移（study→bedroom→ballroom），场景本身是弧线进程的视觉信号。
**色调锁定：** 同一场景段内锁定色调关键词（如 warm amber lighting），仅幕转换时切换（电影 color script 方法）。**180 度轴线：** 同一场景中角色左右关系不可翻转（A 在左 B 在右则保持）。**视觉链条：** 相邻两页至少 1 个视觉元素承接（角色/物件/色调/光线方向），翻页时读者脑补过渡。
**反射/倒影/镜像纪律：** 反射性/重复性物件（镜面墙/玻璃/水面）在含第二角色或多手的页引发视觉重复（模型把倒影渲成额外肢体/人物）——反射只用于**无第二角色的页**；H 动作页去掉反射或负面压 mirror, reflection, duplicate, extra hands, multiple people, cloned face；"倒影是另一表情/时序/微差"的页改可渲介质（画中像/屏中像/屏风影）或"主格+残迹"（完整写法见 anima-prompt 多角色纪律-投影/倒影介质）。
**时段承载页（时段本身是叙事锚：深夜月下/黎明破晓/正午烈日）：** 分镜"场景"列写**时段基色+环境暗度显式**，禁只靠光源色温对冲暗示（色温对冲只给对比不给绝对暗度，深夜会被读成黄昏）。写法（环境暗度基线句+时段排除句）见 anima-prompt 构图节-时段承载页。

## G4. 母题（Motif）/视觉锚点
- 选 1-2 个元素（门/窗/姿势/衣物状态/道具），每隔 4-8 页再现一次，每次只改变"状态"（开度/光影/表情/凌乱度）；**母题页锁定构图**（同机位同景别），只变内部状态——差异即叙事，读者在重复中感知时间流逝与弧线递进
- **道具链规划（分镜表"道具链状态"列）：** 剧本阶段预分配 1-2 个贯穿道具用于跨页一致；**道具只在镜头可见时写，构图不可见/遮挡时标"省略"**，禁为填表硬凹在场；母题再现由剧情需要驱动，不强制全勤、不强制终页回收句（终态句是叙事自然结果）。道具三档分类（身份符号 L0/手持 L1/环境 L2）与 H 页退场规则见 anima-prompt 道具纪律——**道具可见性优先**，身份符号级每页必含但构图不可见仍省略
- **物证鲁棒性+单调累加器：** 状态信号优先选**大尺度/单向/二元/自索引**物证（服装整体、道具在场/缺席、累积痕迹、大姿态）；脆弱的（表情微变/红印/小道具细部/挂钟日历）升格为形体过表达或交给单调累加器。**未完成%（N1.5）+ 状态进度条（N6）= 单调累加器**：跨页状态信号只增不减，模型漂移被读成"弧线又进了一步"而非"画错"。**累加方向由核心轴定**：堕落弧只增不减（身份坠落类终态禁"穿回/重新武装"，用同服装更残破/留痕，穿回=方向性错误）；认知重构/常识改变类允许**单次叙事性回跳**（整理衣冠离开=正常瞬间，只一次且留物证痕迹：扣错位/断粉笔/镜歪）；升温弧/日常弧的"穿回整理"是正常节律。**累加的是弧线进度物证，不是情绪/情节/色气曲线**（N4 波折回升/G6 喘息回温不受影响）。**异变/纹身/鳞化类身体渐变**：模型渲不出浓度差，只认覆盖范围——分镜每页封顶该页范围（指尖一小片→漫到手背→…，范围只增不减），落脚本按"完成但封顶范围"写，单帧事件禁程度副词（淡淡/微微/初现）
- **前景载荷规划：** wide/广角/书挡/终局页，主角以外的"前景实体"必须有规划——广角页前景只有一个必须可见的小道具时，模型把它放大成主角道具。做法：①母题回收物给**尺寸+状态词**（a small tarnished badge half buried in the asphalt beside his foot），不用裸词+动作句；②前景实体与主体拉开透视层次；③小道具在广角页负面压其放大/图案化形式（oversized X, emblem, crest, insignia）

## G5. 转场与页组
- 相邻页指定**转场类型**（时刻/动作/主体/场景/方面），连续两页同型会平；**奇数页末留悬念钩子，偶数页首爆发**（页组化）——前页收、后页发；氛围休止页用"方面转场"（定格环境细节，时间静止）——即喘息页的理论依据

## G6. 双曲线：情绪曲线 + 色气曲线（黄漫版节奏管理）
黄漫不能只有一条曲线——只有肉没有心=拔作，只有心没有肉=普通漫画。两条并行：
**情绪曲线（管长线）：** 情绪下坡连续超 2 页必须插氛围页（对话/环境/回忆/心理）。作用：防止变拔作——弧线的动力是**精神上的色气**（堕落弧：羞耻/沦陷/认知落差/自我意识消融；升温弧：期待/心悸/确认；日常弧：亲密惯性被打破），心理过程需要呼吸页才能被读者感受。
**色气曲线（管局部）：** 连续 H 页 ≤3-4 页，之后必插 1 页喘息页（表情特写/身体细节/对话/环境），与 N8 防物化合并执行。局部疲劳机制=**性刺激脱敏**，喘息页功能="回温"：重造距离感，让下一轮 H 更有效。
**喘息页的双重职责（关键）：** 喘息页同时服务两条曲线——表面回温（色气曲线），里面必须推进**精神色气**（情绪曲线）：身体细微变化/未完成程度回升/视线语言之外再加一档"心理状态变化"（她意识到什么/选择了什么/抵抗什么）。N1.5 期待-释放循环与 N4 觉醒页都靠喘息页承接，不能让读者觉得"停下来了"。

# NSFW 特化层：剧本设计（先做这个）

## N1. 意图拆解（D0）→ 色气核心先行 + 解构四步（来自 anima-nsfw-prompt）

**D0 意图拆解（前置 D1，生成提案；主题模糊时必做，主题具体时确认+补缺）：** D1 的判别式全是"审查而不规定"——它们验证一个已提出的核心，不负责从模糊输入**生成**核心。模糊主题给的是**载体**（女仆=服装/身份，可画出），不是机制/路径/关系。**先问"是什么故事"，再问"为什么色"，最后问"画面怎么表现"**。产出=**一句式场景简报** `[载体]+[机制方向]+[路径箭头X->Y]+[所有权/结算]+[起点状态]+[最色一刻]+[看点句]`，七问推导式（非穷举，答不出的即缺口）：
1. **载体剥离**：主题词是"载体"（可画出）还是"机制/终态"？缺的层自己补（载体当核心=平庸本）。
2. **机制三向+防默认**：色在夺走/获得/定价哪向？**最顺手的先搁置**，另两向哪个更勾人？（模糊输入下默认选"被支配"最顺手，刻意搁置防公式）。**无机制方向合法**：纯爱=双向获得、日常=无机制——无三向时机制句退化为"关系走向句"（见 D1），不强套。
3. **路径箭头**：写"X->Y"（女仆->宠物），X/Y 须是具体角色态；**写不出箭头=没拆完**。
4. **所有权/结算**：她属于谁/谁下单/结算物=核心视觉（项圈+链）——**无交易结构的弧（纯爱/日常）跳过此问**，核心视觉改用关系物证（初夜灯影/偷情香水味/婚戒，见 D1）。
5. **起点状态/张力源**：本色的关系张力从哪来——**落差**（起点比平均高在哪：高/强/傲/圣洁，等着被击穿）、**期待缺口**（想而未得的距离，N1.5 期待-释放）、**禁忌**（正在打破的规则）、**亲近进度**（关系往深走）？起点状态只是落差型的前提，不是全体通用前提。
6. **最色一刻**：全本最色一页的具体行为+场景。
7. **画面层推导（体位语义×玩法程度×行为类型×角色贴合×视觉焦点域→看点句）**：各层由前几问**推导**，**哪格答不出就停——缺格本身就是设计决策，不必凑齐五格**。①**体位语义**：问"这页的体位/姿态表达什么关系"——单向下压→被动/被支配；双向进入→共谋/主动；服务换价→服务/当众。**先问关系是单向还是双向，再问精神在不在场、导向哪**：单向+精神离场→人偶/瘫软式服从（催眠/洗脑）；单向+精神在场转主动→渴求/迎合；单向+精神在场被锁→僵直/定格（时间停止）；双向+精神都在场→相互渴求（共谋/纯爱）。②**玩法程度**：问"**本核心轴的当前刻度在哪**"（取 D1 定的那条轴，不是只有堕落轴）——轴前段→轻，中段→中，后段→重；程度匹配轴刻度。③**行为类型**：问"**哪个行为最能放大这个核心**"——行为是核心的可见放大，越贴近核心那层越色，不一定是插入；行为由核心推导，**不查行为表**。④**角色贴合**：问"**这玩法动的是她的骄傲、渴望，还是软肋？**"——骄傲→傲娇嘴硬/权力反转/圣洁落差；渴望→她一直想要的被满足或被揭穿；软肋→最脆弱处被戳中。贴合人物>追求新奇。⑤**视觉焦点域**：由 D3 核心视觉锚点推（精神→脸/眼神 glazed；身体→体液/反应；关系→姿态/符号 跪姿/项圈；身份→服装/道具/场景并置）。产出=**看点句** 画面化一句（例：堕落·催眠→"她恍惚跪着机械执行口交，空洞微笑对镜头"；非堕落·初夜→"灯下他笨拙解她背后的带子，她攥紧床单不敢看他，呼吸发烫"）。**看点句=已推导层的聚合输出，缺格不影响它存在**；落剧本段/幕标题旁，每幕一句，不逐页。
**判据=缺口探测**：七问跑一遍，答不出的即缺口；用户已答≥4 问=主题具体，降为确认+补缺。D0 产出 1-2 行进"剧本"段；阶段A 首步执行 D0。

**解构四步（与 nsfw 色气核心分析法同构；判别式"审查而不规定"，技术纪律一条不动）：**
- **D1 拆核心**：写一句色气核心（为什么色）+ **机制句**。判别式：**"去掉它这本就不色——落在意志/身体/关系/身份/空间/规则哪一层？"** 可**主层+辅轴**（妓女化=身份主+关系辅）。**机制句三向子问（维度非穷举）：色在"被夺走"（坠落/强制）、"被获得"（共谋/交易）、还是"被重命名/被定价"（职业化/重构）？** **无机制方向合法**：升温/日常弧没有三向，机制句退化为**关系走向句**（X->Y 只写关系如何变化，不硬套三向）。另问**所有权指认**："她属于谁、谁有使用权、谁下单她执行？用什么结算？"——**结算物即核心视觉**（银币/价码/接客姿态）；无结算物的弧核心视觉=关系物证（初夜灯影/偷情的香水味/婚戒）。**结算物锁剧本层：只在 D3 定义落点页（首尾镜像/轴跃迁/锚点页）要求可见，禁全勤**；H 动作页结算物若构图塞不下，降级为环境物/分版图 inset 或省略，**不硬塞进主动作帧**。

## N1.5 勾人引擎：剧本层怎么维持色气（重要）

1. **延迟点**：设 2-3 个即将发生但被打断/转向的时刻，每延迟一次释放时满足感翻倍
2. **落差铺垫（落差型张力源）**：前 2-3 页建立公众形象，为后续反差铺垫，反差越大色气越强
3. **越界瞬间**：设计 1 次打破规则/界限的转折点（身份/空间/心理防线），通常在第 5-7 页（前戏→正戏过渡）；越界前一刻（犹豫中）是性张力最高的叙事点。**越界不限于剧情/伦理，也含打破结构预期**——某页颠覆本页套路同样制造"惊喜"，为它可有意偏离推荐级结构，但**不可破模型层技术底线**（符号各一次/服装不回跳/排空/同帧矛盾/正负冲突/单调累加器方向——违这些=崩图不是惊喜）

## N3. 事件链（每页一个动作事件，禁幕内状态页）

每页至少选一个视角+一个景别（查 G1 映射表选，要有理由）：表情转折→close-up；服装变化→full body；支配→from below；无力→from above；不安→dutch angle；动态：dynamic pose / motion lines / arching back / trembling 按需。视角/构图/光线具体写法见 anima-prompt 构图节。

## N7.5 决定性瞬间选择（Cartier-Bresson + Newton + 日本"見せ場"概念）
**选"临界态"不选"完成态"**：最勾人的瞬间是临界态——即将达到但尚未达到的那一刻。衣物即将滑落比已脱更色；表情正在忍耐比已崩溃更色；手刚碰到皮肤比已握住更色。**見せ場选择**：选动作"中点"而非"终点"；选表情"临界点"而非"完成态"；选接触"瞬间"而非"持续态"。写法：临界态要显式写，模型默认选完成态（caught mid-action/suspended peak）。
**负空间**：关键色气页留 30-40% 负空间。**局部裁切**：前戏/暗示页只展示手/唇/锁骨/衣摆，不展示全貌。
**"主格+残迹"单格装两时（分版图的安全替代）：** 默认把"上一刻的痕迹 + 当下的临界态"装进同一格；**禁一页多表情递进**（多格画同一人逐档表情：模型无"3 格=同一人"锚定，克隆=结构级错误）——表情递进用**跨页连拍**或本条的"主格+残迹"。
**单帧可读性底线（Tier 0，先于一切档位）：** 单页只允许 **1 个主动作 + 1 个主导表情 + 1 个空间关系**；超过=拆页或砍动作（见 anima-prompt 核心公理）。
**单页使用价值四档（黄漫特有，每页独立成立）：** ①**决定性瞬间**（最高优先）：临界态而非完成态；②**浮想联翩**：负空间/局部裁切/痕迹暗示（N7.7 留白机制）；③**叙事意义**：推动事件链/弧线进度条前进（N3 事件页纪律）；④**单纯好看**：构图/光影/表情足够赏心悦目。每页必须满足至少一档，否则这页废。

## N7.6 前戏设计（boudoir 摄影 + 日本"煽情页"惯例）
前戏段（P3-5）功能：**制造性张力但不直接暴露**。**遮挡优先**：每页至少 1 处遮盖。**衣物状态进度区间**：前戏段锁定"微乱→半褪"：整齐=未开始 | 微乱=前戏中 | 半褪=临界态 | 凌乱但仍在=正戏中 | 脱离=已越界。
**微体态：** 手指攥紧=忍耐/快感前兆 | 脚趾蜷曲=无意识反应 | 嘴唇微开/咬唇=压抑声音 | 身体前倾=欲求 | 后仰但未退开=犹豫但接受。**视线方向**（每页必须指定，写法见 anima-prompt 视线纪律）：低头看自己身体→读者注意身体 | 看向画面外→暗示有人/物 | 两角色视线交汇→对视亲密张力 | 避开视线/闭眼→羞耻/忍耐。**环境张力放大器：** 散落物件="日常被打断" | 镜面/反射=同时展示两角度（注意反射纪律）| 飘动元素=动态/不可控 | 光线变化=时间流逝/情绪转换。

## N7.7 余韵设计（日本"余情"美学 + Freytag 下降动作 + aftercare）
余韵段（最后 1-2 页）功能：**不是"结束"而是"回声"**。**展示"痕迹"不展示"行为"**：散乱床铺/地上衣物/皮肤痕迹/窗外光线变化/角色体态变化。**留白让读者脑补**：余韵页画面信息量降至全序列最低，留白比例最大（50%+ 负空间）。
**余韵类型选择：** **闭合式**（相拥/入睡/满足微笑）；**开放式**（独坐看窗外/表情复杂/一人已离开）；**反转式**（揭示新信息）。**余韵页不出现 explicit 内容**；与第 1 页构成视觉镜像——同场景/同构图/同角色位置，但至少 3 处状态变化。

## N8. NSFW 特有分镜（《Passion and Play: A Guide to Designing Sexual Content in Games》）
- **镜头顺序即语义**：先脸后手=被动反应；先手后脸=主动预期；**垂直机位=权力**（G1 组合公式）
- **入控段镜头层次：** 催眠/入控段按"**道具特写→面部特写（正对镜头）→中景/全景被动**"三层推进，缺层则催眠感下降。入控页面部特写必须 facing the camera directly
- **防物化**：每 2-3 张身体特写后接 1 张表情特写；**对视特写页=亲密戏情绪锚点**，前面需铺垫页
- 参考里番西川贵史：频繁角度变换制造"舞蹈感"节奏——H 段落内每页换机位

## N8.5 视角归属必须明确（POV 歧义）
pov 裸写有歧义。**读者 POV**：pov, first person view + 前景出现"读者自己的手"；**角色 POV**：her point of view, from behind her shoulder / looking at her own reflection，且**禁止前景出现读者手**。视点人物切换页尤其要写归属。**POV 在场证明：** 写 POV 必须含该视角主体的**前景部件**，否则模型直接第三人称化；**分镜-脚本一致**——分镜镜头列定 POV 后，脚本构图行必须写 pov 词。**POV 页"仰头看他"="抬头朝镜头"：** 支配者 POV 下她抬头对视方向就是镜头方向，直接写 looking up toward the camera。（权威写法见 anima-prompt 视线纪律-POV 归属。）

## N9. 模板分配（判据来自长编多次实测）
- **状态机转换页 + 首尾书挡页** → 模板 C（NL 叙事，分号分层，情绪收尾）；**其余一切场景页** → 动态/H 页优先 B+C 混合，简单动作页可用纯模板 B；**过渡/喘息页** → 模板 C 或 A-混
- **判据本质是意图解构：** C="这页在表达什么心理/状态/氛围"，B="这页在发生什么事件"。**一句话说全：主导意图=心理/状态/氛围/认知反差 → C；=行为/事件 → B**
- **B+C 动态混合模板：** B 的 tag 骨架 + C 的环境 NL 氛围句 + C 的 evoking 情绪尾。**余韵/收尾页固定用 C**。混合是第三选项，不是默认——但**动态/H 动作页优先混合**
- **重叠区裁决：** 状态转换页与动作场面页重叠时，看**页面主导意图**——焦点在"状态转变瞬间"→ C；焦点在"性行为过程"→ B。两可时优先 C
- **分阶段混用模板（跨页节奏，从 anima-prompt 移入）：** 套图前段（设定/氛围/诱导）用模板 C 叙事 NL 更有气氛；后段（明确 H 行为）用模板 B 分段 tag-stack 更干净；终态氛围段回 C（"讲故事"页纯 C，"展示身体"页 B+C——判据见 anima-prompt 安全等级节）

## N10. 符号标签分布（核心条件配 + 全本各一次 + 状态机限制）
- **符号按核心性质条件配（D2 推导，非全本必配）：** spiral eyes（催眠/精神性入控专属）、ahegao（身体崩溃峰值，通用）、heart-shaped pupils（恶堕/发情峰值，关系/身体性）——**出现则全本各一次**，之后靠状态眼承接。**非精神性核心禁 spiral**
- **符号豁免（认知重构/常识改变核心）：** 此类核心**全本不用 spiral/ahegao/heart**——符号读成"沉醉/恶堕"，破坏"她以为这正常"的读面；以平静/认真/空洞微笑轴替代。**豁免推广到"读面会破坏她不自觉"的非精神性核心；身体崩溃峰值类核心（发情/强制高潮/身体背叛）仍可用 ahegao**
- **表情档位映射（堕落弧参考，推荐映射非禁令）：** heart-shaped pupils 通常出现在堕落"接受/主动"阶段后；spiral eyes 通常给催眠；ahegao, rolling eyes, tongue out 通常给高潮页；抵抗/羞耻阶段常用 teary eyes, biting lip, heavy blush, gritting teeth（字面库见 anima-prompt NSFW-表情三档字面库）。**非堕落弧另立情绪轨**（升温弧：害羞→回应→主动→全情；日常弧：松弛→被撩→燃起→余韵），不套抵抗/沉醉/崩溃档。**非堕落弧 explicit 页自愿编码：** 自愿 H 页的表情/姿态必须用**情动+主动**编码——表情 soft moan, lips parted, half-lidded eyes, gentle blush, looking up at him；姿态 arms wrapped around him, hands on his back, hips meeting him gently；**禁堕落档强忍词** biting lip, tears, eyes squeezed shut, gripping the sheets, tense, arched away。初夜"疼但自愿"用自愿锚定词表（tears of emotion but holding him close, wincing softly but pulling him nearer, eyes meeting his）。**有意打破映射**正是制造张力的手法——打破时想清楚为什么
- **读面检验（方法论）：** 关键页写完后问**"不看上下文，读者读成什么？"**——读面≠语义就换读面标签或加语境。**独占+可见双问**：①情绪必须落**可视独占特征**（目标情绪编码成该情绪独占的物理特征）；②特征必须**落可见部位**——脸被遮时情绪职责移交身体/姿态。**表情档位靠共享面部词区分必读错档**。每档给**独占视觉特征+服从轴动词主导**：勉强档=**涣散眼（glazed）主导+残泪降为次级+身体服从动词**；抵抗档=teary/biting lip/furrowed（意志在场）；沉醉/高潮档禁 biting lip（嘴部与吐舌/张口互斥，N3 同帧矛盾扫描）。**觉醒/回升页**=realization 瞪眼（非 sharp）+**视线锁触发物**+反摆拍 not at the camera+姿态残留——裸体+握剑+sharp+看镜头=读成战斗凶相
- **"勉强接受"档（堕落弧）：** 催眠刚入控、尚未深入时的 H 场景——**身体已服从，情绪残留羞耻**：tears in her glazed eyes, trembling softly, but body compliant and obedient, hips lifting to meet him（**去 biting lip/furrowed brows/咬牙——与抵抗档区分**）。**禁止 stiff, reluctant, turning away, pushing away**（那是抵抗档词汇=意志在场，会否定催眠感）。**状态机门（堕落弧）：** 服从姿态展示页出现后，其后 H 页表情**只升不降**（沉醉→崩溃），禁止回退到 teary+stiff。渐进：抵抗（teary+僵直）→勉强（残泪+glazed+服从）→沉醉（glazed 加深）→崩溃（ahegao）→终态（empty）。**入控后非 H 的懵态页 tag**：dazed, hazy, half-lidded glazed eyes（不是 hollow/curious）。**角色贴合与状态机仲裁：** D0 Q7④角色贴合是**剧本层选点**——只决定选哪个体位/行为/看点能击穿特质，**不落逐页表情**；逐页表情档一律过状态机门。特质残留只以**状态机兼容形式**出现且**限前中期幕**（终态幕看点句必须让位空洞/服从读面）
- **符号标签任意景别（实测：wide/远景不崩眼）**：符号页位不必强制 close-up。**符号间隔：** 一次性符号标签之间建议**间隔 ≥3-5 页**，防两次峰值被读成同一连续状态
- **符号表情页锁脸可读性：** ahegao/spiral eyes/heart-shaped pupils 所在的脸**必须可读**（正对镜头/不被遮挡）。机位使脸不可读时三选一：**换机位露脸** / **拆页** / **符号让位给状态眼**

# 转义层（需求 → 剧本 → 分镜；先做，非可选）

**为什么：** 需求/点子（"捡了个萝莉养成病娇逆推"）是动机与梗概，分镜表是"每页画什么"。直接从需求跳分镜，单帧事件列只能靠脑补 → 逻辑断、单帧过载、莫名多人。**先扩成完整剧本再切帧**，分镜才有因果可依。

## T1 需求 → 剧本（Script）：叙事完整性
把需求扩写成完整剧本（不是摘要，比下方"剧本段"摘要更全）。结构：
- 分幕（N2）+ 每幕主题与弧线作用（N6 进度条位置）
- 每场：**谁 + 为什么（动机/因果） + 做什么（单事件） + 结果如何**；情绪/对白可选
- 检查：因果链闭合（每个事件有前因后果）；首尾镜像（G2：开篇→终篇肉眼可见的变化）
- 产出：分幕分场的剧本文本。**剧本没通过"因果闭合"检查不许进 T2。**

## T2 剧本 → 分镜（Storyboard）：一帧一事件
把剧本切成 12 列分镜表（页数按 G2 页码模型；列定义见"产出格式"）：
- **切帧**：一个事件节拍 ≥ 复杂 → 拆多页；一页只取一个可见节拍（N3 单节拍纪律，接触点=证据位）；禁止"进行时+结果"双写
- **逻辑**：行间承接（承接列必填）；单帧自解释（不看前后页也能懂这一页）
- **机位**：查 G1/N7；优先稳定区（中景/近景/特写 × 正面/侧面/背面）；危险区自动降级——俯视鸟瞰→改中景侧面；多人同框/紧密纠缠→改特写或拆页；宽景小道具→改近景
- **人数**：单人页 exactly one、双人页 only two；排空纪律见"产出格式"排空全本；禁 crowd/群像（设计人群按【设计人群】标注例外）
- 分镜表每页"单帧事件"列满足：**一个动作动词 + 一个动作对象**

**阶段A 整本骨架：** 先转义（T1 需求→剧本，因果闭合检查；T2 剧本→分镜表切帧+机位降级+人数锁死）；转义内嵌 D0 意图拆解（七问->场景简报）→ D1 拆核心 → D2 转引擎 → D3 定锚点 →为何是这个角色（试金石）→分幕（N2）+20 页标尺（G2）→预分配贯穿道具/母题/锚点卡（G4）→弧线总走势（N6）→填"剧本"段。
**阶段B 逐幕事件链：** 五段+幕内骨架（N5）排事件序（N3），定波折页位（N4）+行为轴变奏（N4，锚定峰值页）+符号/顶点页位（N10）。
**阶段C 逐页精修（每页按需查对应区块）：** 露点档（N5）→镜头（N7/G1）→表情档+视线（N10/N3）→服装+道具链（N6/G4）→承接+标题（G3.5/G5/N3）→模板（N9）。每列填完当刻做该列 mini-check +每行填完做连读测试。
**阶段D 检查：** 按时机过自检清单三组（剧本/分镜/落脚本）。
**阶段门禁（构思期先想后查，防"安全填表"）：** A/B 阶段只过创意区块，**不查护栏**——勾人引擎先行。护栏到 C/D 才逐条核对。**跨页检查不因门禁降级**：表情档/道具链/符号/承接/连读在 C 填表当刻仍执行。
说明：这是"决策顺序参考"不是"每页必走 N 步"；跨页检查永远不降级，填表当刻执行而非拖到最后。
