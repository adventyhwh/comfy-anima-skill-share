# 运行约定（跑批前先按此章）

## 1. 文件分类（output 放哪）

- **默认**：没特别说明，生成物进 `ComfyUI/output/`（自动归档脚本按日期归到 output/YYYY-MM-DD/）。
- **轮次纪律（三类目录通用，强制）**：凡是同一项目会跑多轮（多批任务/多主题测试/多轮迭代），**每轮必须落独立子文件夹，禁止两轮的图混在同一层**：
  - 对比测试批：`output/_compare/YYYY-MM-DD/<项目>/<轮次名>/<变体>/`（轮次名如 `r1_portrait`/`r2_comedy`；该轮对比拼图放轮次文件夹根层）。
  - 自动化迭代测试批（evolving）：`output/evolving/YYYY-MM-DD/<项目>/<轮次>/`——顶层层名固定 **evolving**，内部分日期、项目、轮次。
  - 生产：`output/YYYY-MM-DD/<内容名>/`——自动归档只归到日期层；内容名层靠 filename_prefix 区分或跑完手动归位，同日不同主题/项目绝不混放。
- **对比测试批变体名**：变体名=skill 版本/change 开关，如 `r2_comedy/evolving_dyn`、`r2_comedy/third_chan`。
- **辅助文件纪律**：脚本/日志/jobs.json/设计文档/_runner.py 一律放专用辅助目录（与 output 分离，同样按轮次分），严禁混进 output。
- **交互式迭代（一轮一看）每轮交付**：该轮 MUTATE 页单独拼成一张拼接图（基线|突变 或纯突变皆可），存进**该轮 mutate/ 文件夹**；不做跨轮拼接。

## 2. 对比测试（哪个 skill 版本更好）

- 多子代理并行，各读自己分配的那份 skill 文件，不得互读。
- 三个必须一致：**主题一致、人物一致、种子一致**（同 seed 排除抽卡变量）。
- 其余（分幕/事件链/模板/画师/页数）由子代理按各自 skill 自行发挥。
- 提交同一 ComfyUI 队列：不清队列、不前插、不重启。

## 3. 自动化迭代测试（离开/睡觉时，优化某个 skill）

- 双 skill：一个基线 skill（不动）+ 一个动态 skill（被优化）。
- 循环：动态 skill 生成 → 读图 + PNG 元数据审计 → 按反馈改动态 skill → 再生成验证。每轮只与“最近一次未劣化的动态 skill”比较；一旦确认劣化，立即把动态 skill 回退到劣化前版本，再从该版本继续。基线 skill 全程不动，不参与回退或覆盖。
- 小版本不做长期备份，但每轮修改前必须保留“最近一次未劣化的动态 skill”作为可恢复快照；新版本验证通过后才替换该快照。CHANGELOG.md 追加改了什么、理由、验证结果，以及发生回退时的劣化证据。

## 4. 读图审计问题纪律

- **读图一律多模态直接读**（主会话或子代理 Read PNG；敏感内容/长篇批量派子代理读，防敏感图像进主对话）。不使用外挂视觉模型通道。
- **四问清单**（每次读图逐张过，无论谁读）：①提示词遵循如何 ②整体画面有无崩坏 ③场景是否合理 ④分镜想表达的意思有没有传达出来。
- **追问核实仍然必要**：任何视觉模型（包括主会话自己）都会把物件**归属/数量记错**（如把祭坛固定大十字记成角色手中新十字）——判定"某元素存在/归属/数量"时，用 zoom 放大或重读二次核实，防把失败判成成功。
- 审计节奏：长篇分批读（10 张/批），全部读完再统一重roll（省队列往返）；重roll 后**必须复读验证**，防修复一个坑引进新坑。

## 5. 长篇成片交付（对话框压字）

长篇出图+审计通过后，交付物=压好对话框的成片，只交无字原图不算完成。

- **台词文风**：学漫画。**对白**=人物口语，怎么说话就怎么写（内心独白也是对白，用思考泡）。**旁白**只做画面做不到的事——时间/地点锚（「翌朝。」「台风夜。」）、画外信息一句带过；**不描述画面**，画面画了的东西再写一遍就是小说。判据：删掉这行旁白，画面信息没损失就删。禁文艺腔与报告腔。**写对话框阶段激活** `references/dialogue-style.md`（入口）：按作品档位只翻对应文件——safe→`dialogue-style-safe.md`、sensitive→`dialogue-style-sensitive.md`、nsfw→`dialogue-style-nsfw.md`，通用部分见 `dialogue-style-common.md`（每个档位都要过，很短）。**不写的那几篇不翻开**（省预算、防档位腔调串味）。**同档位页集中一批写完再切档。**每句对白对照后落笔。**对白永远用中文，禁日式语尾（ね/よ/な/だっ）与翻译腔——参考只吸收结构不抄原文。**
- **三种件**：对白=白气泡+尾巴指向说话人；内心独白=思考泡+圆点；旁白=米色框。
- **流程**：读图后**先按分镜表把每页标好档位**（safe/sensitive/nsfw），然后**同档位页集中一批写台词+定坐标**（避脸避主体；激活该档位文件+common，写完全档再切下一档，不按页码 1,2,3,4 逐页写——防档位腔调串味），存 `captions_<书>.md`；压完抽查 3 页。压字用自写脚本（bake_bubble 思路：台词+坐标表驱动；换行、防超宽、行尾孤字+行头标点禁则已内置——实测长句会在行首掉出逗号，禁则必须两条都有）。
- **产出**：日期文件夹根层=成片（`P01_标题.png`）；`_raw/`=无字原图；`_reject/`=废案（带原因命名，重roll 旧版逐张移入，别只数数量）。output 根目录不留散图。

## 6. 出图踩坑速查（实测验证）

写 prompt 前扫一遍，每条=一个已验证的规避动作：

- **双人 OC 同框串染**（两人合一人/异色瞳/发色互染）：`2girls` 锚 + 每角色一个连续段（句首 the senior/the junior）+ 负面 `heterochromia`；发色用强先验词（blonde/black），弱词（flaxen）会被服装染色。实测双人本重roll 大头全在这，三件套后归零。
- **对话/展示类措辞触发漫画分格**：负面常驻 `multiple views, comic, speech bubble`；措辞避开 explain/show/present。
- **传递/交接单帧只落完成态**（糖已掰好、相机已在手中+对方空手）：交接过程特写必崩（无主之手、双相机）。屏幕内容用泛光+反应承担，禁可读文字；纸张保留模糊字迹。
- **悬停/漂浮站桩先验极强**：俯拍+地面在脚下远处+负面 standing on ground；三刀不改就让台词反杀（「……并没有离地。」）。
- **歧义渲染要写死**：shotgun microphone 会渲成真枪（改 a fuzzy interview microphone on a short handle）；湿身写 soaked through / wet hair plastered；时段页带暗度基线（no daylight/dusk）。
- **反射物件只进无第二角色的页**；"镜中像"梗改画中像或破镜框。
- **设计人群页**：正面不写 no other people、负面不压 strangers/crowd，人群用剪影+灯海，负面加 cloned face 防复制脸。
- **手部微动作（笔悬空）是弱载体**，叙事钩子别押；能用 canon 角色就用（同人名字即锚重roll率 1/30，OC 群像 7/30）。

## 7. 点子库使用纪律

- 若本地建有**角色/主题点子库**：只检索、不整读——角色卡类大文件严禁整读（上下文瞬间爆炸），用查询脚本按需提取单卡；小分类文件按需只读当下要用的那一两类。
- 角色位默认从库检索（全女锚点，正好匹配需求）；男角色才现场搜。

## 8. 跑批提交与服务器运维

- **整批一次性提交（默认跑批方式）**：多图批量建议写个整批提交脚本（先把全部任务 POST 进 ComfyUI 队列，秒级全部入队，再逐个 poll 收结果）。禁止逐张串行提交等待：每张一次客户端启动+提交间隔，且用户网页排任务时会撞逐张超时。任务表每项 `{"tag","pos","neg","size","seed"}`；先 `--dry-run` 验证图构建，负权重画师串的 NegPip 拆分工具内自动做。
- **批量提交脚本无 subfolder 字段（踩坑）**：若批量提交脚本不支持 subfolder，用它跑的测试批文件会落 output 根目录被自动归档走生产路由。**对比/测试批跑完立即手动归位到 §1 约定的轮次文件夹**，别依赖自动归档。
- **队列共存纪律**：用户自己在网页排的任务不清理、不前插、不重启；我的批等队列排空再入队，或直接入队按 FIFO 与用户任务交错完成（poll 按 prompt_id 各等各的，插队不影响）。
- **服务器卡死识别与重启**：症状=提交后 log 长时间无完成标记且 `/queue` 里 running 任务不是自己的、server log 里 tqdm 停滞——是残留旧 KSampler 卡死堵队列，杀进程重启（杀命令行含 ComfyUI 的 python* 进程 + 清 8188 端口）。**重启脚本要带 cd 到 ComfyUI 目录**——bash 工具 cwd 会漂回项目目录，手敲 nohup 不带 cd 会因相对路径起不来。重启后 `/queue` 应为空，旧队列任务即被丢弃。
