# 对白通用部分（safe / sensitive / nsfw 共用）

> 每个档位写之前都过一遍这篇，很短。具体招式在各档位篇里。

## 通用红线
- **旁白化对白**：对白在复述画面（「雨点打在我脸上」）→ 删，画面交给图
- **说明书对白**：一口气交代设定、身份、背景
- **全员一个腔调**：所有角色共用同一套省略号+～+语气词——每个角色要有自己的叹词/口头禅（口头禅是锚定声线最省力的办法）
- **日语直译语序**：不换结构直接搬日文句式
- **每句都是完整书面陈述**：零叹词、零停顿、零语气词

## 通用符号表
| 符号 | 意思 | 主要档位 |
|---|---|---|
| 「」 | 对白引号 | 全部 |
| ……（2 个点） | 犹豫/拖尾 | safe / sensitive |
| ………（3+ 个点） | 更长的沉默 | 压抑（safe） |
| ～ | 拖音 | safe 日常 |
| ♪ | 俏皮/好心情 | safe 日常 |
| ♡ ♥ | 爱意/沉溺 | sensitive / nsfw |
| 、 | 口吃/顿挫 | 全部 |
| ！？／！！／？？ | 情绪强度 | safe 热血 / nsfw |
| —— | 中断/被打断 | 全部（破折号=话被截断，省略号=自己说不下去） |
| （ ） | 内心小字/低语 | 全部 |
| \c[n] | 颜色标签 | 语料里 RPG Maker 脚本用，写作时不写进对白 |

## 落笔流程（判据 + 自检）
1. 先定档位（safe / sensitive / nsfw），翻对应篇目选招。
2. 写完一句**读出声**：没有任何叹词/停顿/语气词、像书面语 → 板，重写。
3. 自检三问：这行删掉，画面信息有没有损失？→ 有损失就是旁白，不属于对白。这行除了交代信息，给了情绪吗？这句话换另一个人说，有区别吗？（声线）
4. 对白≠旁白：旁白走「短戳」规则（时间/地点锚、一句画外信息），不套活人气。

## 纪律
**对白永远用中文写。只吸收结构，不复制日语原文，不写日式语尾（ね/よ/な/だっ），不写翻译腔。** 参考是工具箱，写出来的是你自己的句子。

## 日文结构对应（照此转中文，勿抄日语）
口吃顿 い、＝X、X；叹词 あ/え/う/わ＝哇/哎呀/诶/唔/呼；语尾 ね/よ/な＝吧/呢/啦/哦/嘛。
