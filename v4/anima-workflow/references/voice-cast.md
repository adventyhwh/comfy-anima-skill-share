# 声线卡（voice-cast）——角色对白区分度

> 定位一句话：**声线卡管"这话不像他会说的"，不管"这话该怎么写"。** 排除错误的，剩下的在合适范围内自由发挥——限制太死，台词就死人味了。

## 防的是什么
common 红线三"全员一个腔调"的落地工具。长篇多角色时，模型默认把所有人写成同一个人的不同音量。开书时给每个角色钉 1-3 个**排除性**锚点，压字时对照；遮住名字能认出是谁 = 及格。

## 核心原则：排除法，不是填表法
- **只钉"绝不会"**：卡片锁的是该角色的禁区（不会用的词/语气/句式），不是必须使用的台词零件。填得越满越死人味。
- **锚点 ≠ 每句必带**：口头禅是辨识度筹码，出现即提醒；连续几页句句都带 = 过密，模型会靠它偷懒凑区分度。出现率两三成封顶，留白也是声线。
- **发挥是默认态**：锚点与禁区之外随便写——句长、节奏、情绪都该随场景浮动。**声线漂移合法**：角色状态变了（入控/沉醉/崩溃，接 doujin-plan 表情档位），语气跟着走才算角色活着；卡锁的是底色，不是恒定态。
- **卡片超过五行就砍**：区分度靠 1-3 个强特征；特征堆多了，模型每句都在执行清单。

## 卡片格式（每角色几行，开书填一次）
```
【角色名】
锚（1-3）：口头禅/叹词、句长节奏（短促/绵长）、称呼习惯（自称/叫人）
禁区（绝不会）：措辞 / 语气 / 内容
（可选）档位走音：safe 偏 X；nsfw 偏 Y——跨档变化明显才写
```
示例（注意多轻）：
```
【修女】
锚：自称"我"从不停顿（自信底色）；训诫只用短句
禁区：不撒娇、不用～和♪、不主动开口谈欲望（explicit 档也不破例——渴求写进动作和咽回去的半句）
```
——除此之外的一切写法自由，由当页剧情定。

## 公开角色 vs OC（规则相反，同 anima-prompt 名字即锚）
- **公开角色**：声线读者心里已有，卡只填**本作排除项**（防 OOC 的 2-3 条），不要试图重新定义人家怎么说话。
- **OC**：读者心里没有，卡照常填；OC 名字不锁声线，全靠这几行。

## 落笔自检（三问）
1. **认人**：遮住名字，这行认得出是谁吗？（不能→检查是否用了锚点或踩了别人的禁区）
2. **换人**：这行换另一个角色说完全成立？（成立→没区分度，重写）
3. **过密**：最近几页锚点词句句出现？（是→删到两三成）

## 位置
与 doujin-plan 锚点卡同批填（锚点卡锁外观，声线卡锁声音）；压字阶段与 dialogue-style 档位篇并用，每句对照角色卡落笔。
