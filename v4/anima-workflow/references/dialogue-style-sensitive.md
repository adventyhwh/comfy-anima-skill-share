# Sensitive 对白篇（擦边 / 暧昧，过渡用）

> 介于 safe 与 nsfw 之间：脸红、欲言又止、贴近耳边的低语、没越线的亲密。作品里不出现这层就跳过本篇。写这篇也过一遍 `dialogue-style-common.md`。

## 风格指引
- **欲言又止**：省略号把话咽回去「……你、你在看哪里啦！」
- **低语**：短句 + 音量感（小声/贴着耳朵），句尾轻
- **间接表达**：不直说心意，绕弯或交给动作：「要是……再靠近一点点的话……」
- **空间留白**：靠近、凑近、别贴这么近——用距离写张力
- **回避视线**：不正面接话，用转移「……我才没有在看你呢！」
- **气氛靠节奏不靠形容词**：心跳、气息、一阵沉默，用省略号隔开

## 示例参考
- 「……你、你在看哪里啦！」
- 「别、别靠这么近……会被人看见的……」
- 「要是……再靠近一点点的话……就……」
- 「嗯……没事的，我相信你……」
- 「刚才那个……不是故意要看的！」
- 「……我才没有在看你呢！」
- 「那个……我可以……握住你的手吗……？」

## 禁用于本档（词 + 风格）
- 不直露器官/动作词（那是 nsfw 的事，这档一露就破功）
- 不把擦边写成露骨；也不写成纯 safe 日常（那样没张力）
- 不用 ♡ 堆叠（那是 nsfw 的沉溺记号，这档最多轻用一次）
