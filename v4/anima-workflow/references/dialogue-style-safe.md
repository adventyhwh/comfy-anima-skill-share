# Safe 对白篇（日常 / 热血 / 悲伤 / 压抑）

> 本篇=无性内容对白。写这类读这篇 + `dialogue-style-common.md`（通用部分）。色气内容在 sensitive / nsfw 篇。

## 风格指引

### 日常/轻松（卖点：活泼、亲近、节奏快）
- 叹词开口：「哇——！」「诶，别卖关子了嘛……」
- 省略号做节奏：犹豫「……嗯。」／被断「那、那个……能借用一下厕所吗！？」
- 语尾语气词落地：吧/呢/啦/哦/嘛——「就这样再来一次吧♥」
- ～ 拖音 + ♪ 俏皮：情绪上扬时用，别每句都上
- 口吃顿 、：紧张/结巴「不、现在必须去上厕所……！」
- 拟态叠词：「毛茸茸毛茸茸～～！！」「软乎乎的好治愈～♪」

### 热血/冒险（卖点：气势、冲劲）
- 短句 + 叹词强收：「上吧——！」「别小看我啊——！！」
- 呼喊/命令式，句尾重音；少用省略号（犹豫会泄气）
- 报数/递进节奏：「一、二、三——上！」

### 悲伤/感动（卖点：克制）
- 省略号为主，句子短、停顿多，语尾轻放（……吧 / ……呢）
- 不说「我很难过」，说动作和感官：「……总觉得，这里的雨，好凉啊。」
- 重话轻说：越是重大的事，句子越短越平

### 压抑/黑暗（卖点：沉默）
- 陈述句冷收，语气词近零
- 「……」当重器；长句心理 + 短句重击交替
- 情绪用「没说出口的」表达，留白给读者

## 禁用于本档（词 + 风格）
- 情绪名词直说（「我很愤怒/悲伤」）→ 用动作、感官、断句代替
- 书面连接词（然而/于是/因此）进口语
- 翻译腔（「……的样子」「……的感觉」、被字句连发）
- 用力过猛：一句堆 >2 个语气词，或句句叹词+～
- 热血档用省略号拖尾（泄气）；悲伤/压抑档用叹词开场（跳戏）
- 本档不出现性描写词（器官/动作）——那是 nsfw 篇的
