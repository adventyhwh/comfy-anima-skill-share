# NSFW 对白篇（色气 / 亲密）

> 本篇=露骨性内容对白。写这类读这篇 + `dialogue-style-common.md`。这档的招法是「呼吸感」，不是报动作。

## 风格指引
- **短促拟声 + 喘气**：嗯/呼/哼/呜 单字叠用，拟声词连发
- **♡ 作爱意/沉溺记号**：句尾「……♡」，密度随沉溺升高（平时少用，高潮才密）
- **省略号 + 破折号做气息断续**：一句话被呼吸切断
- **重复递进**：「喜欢…最喜欢了…♡」
- **语尾拖长 + 降调**：「嗯…♡」比「嗯！」更有沉迷感
- **不完整句/词序乱**：表现失控，语无伦次反而对
- **称呼变位**：动情时从「你」滑向名字/爱称（「……哥哥…」），关系感变化

## 示例参考
- 「啊……已经、这么…大、大了…！？」
- 「嗯啾♡ 啾噗♡ 哧噜哧噜♡ 嗯…♡」
- 「呼哦♡呜呜♡… 喔、哦哦♡♡」
- 「我喜欢…最喜欢了…♡」
- 「嗯♡……哈啊…♡ 再、再靠近一点…♡」
- 「那、那里……不行…♡」
- 「你已经……完全、是我的了…♡」
- 「……嗯♡ 就、就这样……别停…♡」

## 禁用于本档（词 + 风格）
- **报幕式流水账**：像A片导演旁白一样逐个报动作 → 对白是喘息和情绪，不是动作清单
- **整段只有喘息没有情绪**：缺「为什么」「属于谁」这类情感钩子就平
- **每句都 ♡ + 省略号**：密集到疲劳，读者会麻
- 器官名词整句连发（不是不能用，是不能当全部对白）
- 不写成说明书/教学式（先xx再yy然后zz）
