# 对白写法参考（入口）

> 定位一句话：**对白是让人物活起来的声音，不是剧情说明书。** 数字堆一堆没用，能落笔才作数——各档位篇里全是可直接照做的规则、例子和红线。

## 何时用
anima-workflow §5 长篇成片**写对话框（压字）阶段激活**，每句对白逐句对照；短篇/单图台词同样适用。平时不读，写台词时再翻开。

## 怎么翻（按档位只读一篇 + 通用篇，别全读）
| 档位 | 文件 | 适用内容 |
|---|---|---|
| Safe | `dialogue-style-safe.md` | 日常 / 热血 / 悲伤 / 压抑 |
| Sensitive | `dialogue-style-sensitive.md` | 擦边 / 暧昧（过渡用，作品没这层就跳过） |
| NSFW | `dialogue-style-nsfw.md` | 色气 / 亲密 |
| 通用 | `dialogue-style-common.md` | 红线 / 符号 / 落笔流程 / 纪律（每个档位都过一遍，很短） |

**写哪档读哪篇 + 通用篇；不写的那几篇不翻开**——省上下文预算，也防止别的档位的腔调串进来。

**按档位分批**：先把同档位页的对话框全部做完再切下一档，不按页码逐页写（防档位腔调串味）。

## 语料来源
从多部商用 eroge 的明文事件脚本提取语料（RPG Maker / Unity / Godot Dialogic 等引擎格式），只吸收结构和语感，不抄原文。
